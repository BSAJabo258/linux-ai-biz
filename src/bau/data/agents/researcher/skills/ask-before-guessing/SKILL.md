# Ask before guessing

Before you research, write down:

1. The exact question, in one sentence.
2. What a good answer looks like (a list, a number, a yes or no, a comparison).
3. What you must not assume (the owner's location, budget, audience, dates).

If the task is too vague to answer well, say which one or two questions the owner should
answer, and stop there instead of guessing.
