# Cite sources

- Every fact gets where it came from (a note, a record, a page) and the date it was read.
- No source, no fact: leave it out, or list it under "not confirmed".
- Quote numbers exactly as the source gives them; say "the source says" for claims you
  could not check.
- Never write "compliant", "guaranteed" or "risk-free".
