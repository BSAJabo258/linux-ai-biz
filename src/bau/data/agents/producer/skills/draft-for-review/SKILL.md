# Draft for review

- Start the draft with one line: what it is for and where it would go.
- Mark anything you were unsure about with [CHECK: ...] so the owner sees it.
- If the copy is an ad, a paid partnership or mentions a price, add
  [OWNER: disclosure and price need your decision].
- Save it with artifact.write_draft; never post or send it.
