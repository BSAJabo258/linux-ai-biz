# Setup: before the first week

1. Make or open your creator profile (docs/VIRTUAL-CREATOR.md) and run `bau creator check`.
2. Copy the persona's details into `_shared/persona.md` and its voice into `_shared/voice.md`
   (replace every `{{...}}`).
3. Read `_shared/platform-rules.md` and change anything that does not match your accounts.

A stage will not run while a reference file still has `{{...}}` placeholders.
