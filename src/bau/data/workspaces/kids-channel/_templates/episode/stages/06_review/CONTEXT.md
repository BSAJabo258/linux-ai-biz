# 06_review: you make it and watch it

No agent works this stage: it's yours.

## Agent
none

## Inputs
- Working (this run): ../04_video-prompts/output/video-prompts.md
- Working (this run): ../05_metadata/output/metadata.md

## Process
1. Generate each scene with your video generator from the prompts, then edit them
   together with the voice and music (music you have the rights to).
2. Watch the whole video, start to finish.
3. Write `output/review.md`: where the video file is, and one line per point below.
4. Queue it: `bau youtube add <video> --title "..." --description "..." --tags ... --kids --category 27`
   (copy title, description and tags from the metadata), then `bau youtube review`.

## Outputs
- review.md → output/

## Human check
You watched it end to end, it's right for young children, and it goes out made for kids.
