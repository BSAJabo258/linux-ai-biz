# 02_script: narration and dialogue

One job: write the full script from the pitch.

## Inputs
- Working (this run): ../01_pitch/output/pitch.md
- Reference (every run): ../../../../_shared/series-bible.md
- Reference (every run): ../../../../_shared/voice.md
- Reference (every run): ../../../../_shared/kids-rules.md

## Process
1. Follow the pitch's story and learning goal exactly.
2. Write narration and dialogue in the voice, at the episode length in the bible.
3. Mark each new scene with a line starting `SCENE:` and a few words of where we are.

## Outputs
- script.md → output/

## Human check
Read it aloud. Is it calm and right for the age band? Fix anything the kids check found.
