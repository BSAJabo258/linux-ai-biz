# 01_pitch: one new story

One job: turn the owner's idea into a one-paragraph episode pitch.

## Inputs
- Working (this run): ../../brief.md
- Reference (every run): ../../../../_shared/series-bible.md
- Reference (every run): ../../../../_shared/kids-rules.md
- Reference (every run): ../../../../_index/episodes.md

## Process
1. Read the idea in the brief.
2. Write a working title, one learning goal, and the story in one paragraph: the small
   problem, what the characters try, how they solve it together.
3. Make it clearly different from every episode in the episodes list.

## Outputs
- pitch.md → output/

## Human check
Is this a new story, not an earlier one with new names? Is there exactly one learning goal?
Edit the pitch in place; the script is written from whatever is there.
