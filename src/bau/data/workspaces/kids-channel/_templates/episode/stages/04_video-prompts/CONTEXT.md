# 04_video-prompts: one prompt per scene

One job: write a video-generator prompt for every scene.

## Inputs
- Working (this run): ../03_storyboard/output/storyboard.md
- Reference (every run): ../../../../_shared/series-bible.md
- Reference (every run): ../../../../_shared/kids-rules.md

## Process
1. One prompt per scene, numbered like the storyboard.
2. Describe every character exactly as the bible does, every time, so they look the same
   in every clip.
3. Gentle colours, soft light, slow camera moves. Nothing frightening.

## Outputs
- video-prompts.md → output/

## Checks
- kids_text

## Human check
Do the characters look the same in every prompt? Is anything another company's character?
