# Engineering rules

Before coding:
- Understand requirements.
- Understand constraints.
- Identify risks.
- Define success criteria.

During coding:
- Small commits.
- Small changes.
- Frequent tests.
- Clear documentation.

After coding:
- Run tests.
- Review logs.
- Check security.
- Update documentation.
- Verify deployment.

Never merge untested code. Never deploy unknown behavior. Never assume success. Verify
success.
